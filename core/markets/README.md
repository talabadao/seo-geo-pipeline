# core/markets — quy tắc theo thị trường & ngôn ngữ

Mỗi file (mã locale, ví dụ en.md, th-TH.md): chính tả/biến thể, giọng địa phương, định dạng số/
ngày/tiền, SERP location để tra cứu, domain nên loại khi phân tích đối thủ, lưu ý dịch. Skill ghép
market sau industry (CLAUDE.md §6). `languages.primary/secondary` trong config trỏ tới các file này.

Ngôn ngữ dịch hay dùng (từ các dự án): th-TH, vi-VN, ko-KR, ja-JP, zh-Hans, zh-Hant, ru-RU, es-ES,
fr-FR, de-DE. File chưa có thì tạo theo khuôn en.md.
