# Rule internal link

- Mỗi bài ≥ `config.yaml › content.min_internal_links` (mặc định 2) internal link.
- Dùng URL THẬT từ `project/brand/internal-links.csv` (crawl sitemap / tab Site URL). Không bịa URL.
- Anchor mô tả ("see how Kiara runs 18 production lines"), KHÔNG "click here"/URL trần.
- Link tới trang CỤ THỂ hợp nhất, không chỉ homepage.
- Velocity → trỏ về Infrastructure liên quan + nối ngang Velocity cùng cụm.
- Mỗi bài kết bằng một CTA rõ dẫn tới trang chuyển đổi (và profile PDF nếu hợp).
- Outbound: tới nguồn chuẩn/tổ chức có thẩm quyền (hỗ trợ E-E-A-T). KHÔNG link đối thủ, OTA, site
  khách hàng, marketplace sourcing.
- Bản dịch: internal link đổi sang path ngôn ngữ đó (ví dụ /th/...), map từ glossary/bản đồ link.
