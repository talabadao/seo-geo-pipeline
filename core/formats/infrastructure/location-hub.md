# Format: Location Hub  (Infrastructure)

Intent: Local/Navigational. Trung tâm về vị trí + cách đến (rất quan trọng với khách sạn).

## Cấu trúc
- H1: "<brand> Location / Getting Here"
- Bản đồ + NAP chuẩn; khoảng cách/thời gian thật tới ga/sân bay/landmark (bảng)
- Các cách đến (nối how-to-get-there); landmark quanh đó (nối things-to-do/area)
- CTA đặt phòng; link xuống các bài Velocity location

## Schema: Hotel node + geo + hasMap; BreadcrumbList.
## Must: số khoảng cách/thời gian thật; NAP khớp mọi nơi; đích internal link cụm location.
## Pitfalls: cập nhật tuyến/giờ; gộp các trang transport trùng/cũ.
